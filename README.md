# madori — 暮らしを、描こう。

無料・端末内動作の、2D間取り作成と家具配置・3D閲覧のブラウザアプリ。

## できること

- ドラッグで壁を描き、あとから実寸を入力
- 部屋の自動検出、名前と床面積の表示
- 自分の家具を名称・分類・幅・奥行・高さで登録して配置
- 家具の移動、回転、複製、寸法変更
- ドア・引き戸・窓・浴槽・トイレ・コンセントの配置
- 3Dの回転・拡大表示、壁の切り替え
- 端末内自動保存、JSONバックアップと読込、2D SVG出力
- スマホ・タブレット用レイアウト、オフライン用アプリシェル

データは各端末に保存されます。家族と同じ間取りを使う場合は「保存」のJSONファイルを渡し、相手の端末で「読込」してください。クラウド同期やアカウントはありません。

## 開発・起動

Node.js 22.13以上を使用します。

```powershell
npm install
npm run dev
```

`http://localhost:5173/` を開きます。同じWi-Fiの端末からは、ターミナルに表示されるNetwork URLで開けます。OSのファイアウォール設定は自分で許可してください。HTMLの直接ダブルクリック起動はサポートしていません。

## GitHub Pagesで使う

公開先: **https://yuzora-yu.github.io/madori/** （Pagesの有効化と最初のデプロイ後）

リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。`main` へPushするたびにチェックとビルドを行い、成功したものを自動公開します。公開リポジトリならGitHub FreeのPagesで利用できます。公開サイトにはアプリだけが含まれ、各端末の間取りや家具データはアップロードしません。

HTTPSの公開版は一度読み込むとアプリ資材をキャッシュします。初回オフライン準備の完了後は2D・3Dとも通信せずに使えます。ブラウザがキャッシュや保存データを消す場合に備え、JSONバックアップを残してください。更新版は古いタブをすべて閉じてから再度開くと適用されます。
