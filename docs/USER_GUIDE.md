# madori — 間取りと家具配置シミュレーター

無料で端末内動作するブラウザアプリです。

## 起動

```powershell
npm install
npm run dev
```

ブラウザで http://localhost:5173/ を開きます。HTMLを直接ダブルクリックする方式ではなく、上記のローカルサーバーで利用します。外部APIやアカウント、課金は不要です。

## 操作

1. ヘッダーの間取りメニュー、または右下の「新しい間取り」を選びます。最初に表示されるのは編集可能なサンプルです。
2. 「壁を描く」でドラッグして直線の壁を描きます。端点同士をつなぐと部屋を自動検出します。壁の途中へ接続したり、交差する壁を描くこともできます。
3. 「選択」で壁をクリックし、右側の長さ・高さ・厚みを指定します。長さは接続する壁の内側から内側までの内寸です。四角い部屋を選ぶと内寸の幅・奥行を直接入力できます。右・下の壁と連続する壁を移動し、隣の部屋の寸法も変わります。四角い部屋の一辺全体に対応する壁は部屋寸法として変更し、その他の壁は始点固定で終点と接続壁を動かします。部屋名と2Dの床色も編集できます。
4. 「家具をつくる」で名称・分類・幅・奥行・高さ・色・形状を登録します。一覧の「配置する」で表示し、ドラッグで移動します。右側で正確な位置・寸法・角度を指定できます。
5. ドア・引き戸・窓・浴槽・トイレ・コンセントはツールまたは建具・設備一覧から選んでキャンバスをクリックします。ドア・窓等は近くの壁に自動整列します。配置後も移動と寸法編集が可能です。
6. 「3D」に切り替えて配置を確認します。ドラッグで回転、ホイールで拡大縮小、右ドラッグで移動します。「壁を低くして内部を見る」で壁の見え方を切り替えます。

2Dではホイールで拡大縮小、右クリックを押したままドラッグ、または移動ツールで画面移動（従来のAlt＋ドラッグ・中ボタンドラッグも使用できます）。「全体を表示」で見失った間取りへ戻ります。

ショートカット: V = 選択、W = 壁、N = 1か所のメモ、M = 2点の寸法メモ、R = 家具を90度回転、Delete = 削除、Ctrl/Cmd＋Z = 元に戻す、Ctrl/Cmd＋Shift＋Z = やり直す。

## 編集画面を広く使う

- 上部の「広く使う」またはFキーでヘッダーと左右のパネルを隠し、2D・3Dの編集領域を広げます。「通常表示に戻す」（スマホでは「戻る」）、Fキー、Escキーで元の表示に戻せます。寸法などの入力中は文字入力を優先します。
- 「家具・設備」「設定」で各パネルを開閉できます。PCの通常表示では左右を個別に閉じられます。広い表示から戻すと以前のパネル状態に戻ります。
- スマホ・タブレットではパネルは最初から閉じています。必要なときだけ一つ開き、×ボタンかパネルの外側で閉じます。家具の「配置する」や設備の選択後は自動で図面に戻ります。家具を選ぶだけではパネルは開かず、「寸法を編集」から編集できます。
- 拡大縮小・全体表示・画面移動の操作バーは図面の右下にあります。画面の広さを変更しても中心位置・ズームを保ちます。全体が見えない場合は操作バーの「全体を表示」を押します。
- 小さい画面で描画ツールが収まらない場合は、ツール列を横へスクロールできます。入力欄はスマホでも操作しやすい大きさにしています。
- 広い表示でも保存ボタンと2D・3D切替は使えます。読込やプロジェクト名の変更は通常表示に戻して行います。

## 保存

- 編集はブラウザのlocalStorageに自動保存します。保存場所はブラウザとURLごとに異なります。
- 「保存」で間取りと家具一覧を `.madori.json` にダウンロードします。「読込」で復元・他端末への持ち込みができます。ブラウザデータを消す前にJSONを保存してください。
- 「2D図面をSVG出力」でベクター図面を保存できます。
- 読み込めない形式の自動保存が見つかった場合、自動保存を停止し、元データを保護します。明示的な読込または新規作成で再開します。
- 元に戻す／やり直すの履歴は最大50操作で、再読込するとリセットされます。

## 現在の仕様と範囲

- 寸法・面積は壁の厚みを差し引いた内寸です。初期の壁厚は12 cm。実際の厚みを入力すると内寸も変わります。壁が途中で分割されている場合、寸法線は各区間の内寸を表示します。変形した部屋の寸法は各壁を選んで変更します。家具配置の検討に使う数値です。
- 3D家具は登録寸法に基づく簡易モデルです。窓の下端の高さは初期90 cmで変更でき、コンセントの高さは床からの配置高さとして扱います。2Dで設定した部屋の床色は3Dでは共通の木床になります。
- 家具一覧の編集は配置済みの同じ家具にも反映します。右側のプロパティ編集はその配置物のみを変更します。
- 複数階、手描き画像の自動認識、曲線壁、衝突判定、施工用CAD出力は今回の実装範囲外です。
- 3DにはWebGL対応ブラウザが必要です。描画できない場合は2Dをご利用ください。
- GitHub Pagesで公開できます。デスクトップアプリ化は必要になった際にユーザーが選択できます。

## 品質確認

```powershell
npm run typecheck
npm test
npm run lint
npm run build
```

2D編集はSVG、3Dは遅延読込のThree.js。3Dは操作とサイズ変更の際のみ描画し、外部画像・フォントは読み込みません。コードは `app/floorplan/`、純粋な幾何・保存形式ロジックは `packages/floorplan/` にあります。

## ドアと造作棚

- ドアを選択すると「蝶番」の左右、「開く側」、0〜180度の「開く角度」を変更できます。左右・上下は回転前のドアを基準にします。2Dの軌跡と3Dの扉は同じ設定で表示します。
- 「造作棚をつくる」で幅・奥行・高さ・段数・床からの高さを登録し、「配置する」で配置します。家具の形状から「造作棚」を選ぶこともできます。段数は収納スペースの数で、棚板は段数＋1枚です。床からの高さは棚の底までの距離です。3Dでは側板・背板・棚板のある形を表示します。個別の棚も右側で編集できます。
- 保存形式はバージョン5です。以前のバージョン1・2・3・4は壁や家具の座標を移動せずに読み込みます。バージョン1には旧2Dに合わせたドア設定も補います。内寸表示へ切り替わるため、旧版とは寸法・面積の表示値が変わります。

## 窓の寸法と壁からの距離

- 窓を選び「設定」または「寸法を編集」を開くと、「窓の幅」「見込み（厚み）」「窓の高さ」を入力できます。「床から窓の下端まで」は初期90 cmで、3Dの窓と壁の開口にも反映します。
- 壁に沿った窓には「左／右の内壁から」（縦の壁は「上／下の内壁から」）が表示されます。隣の壁の内側から、窓の近い端までの距離です。中心までの距離ではありません。いずれかの値を入力すると窓が移動し、反対側の値も更新されます。
- 窓の幅・高さ・両端の内壁からの距離は既定で常時表示します。ツールバーの「窓寸法」で切替可能です。選択中はA／Bの測定端も表示します。幅を変更すると、A側（横の壁は左、縦の壁は上）の距離を保ちます。壁の内寸を越える入力は適用しません。
- 壁が途中で分かれている場合、その窓がある壁区間が測定範囲です。A・Bの位置を見て実測位置を確認してください。壁に沿っていない窓は先に壁の近くへドラッグして沿わせます。
- 詳細寸法は既存の座標・寸法・設置高さとして保存します。以前のデータもそのまま読み込めます。窓寸法はPNG・SVG・印刷にも含みます。選択中だけのA／Bマーカーは出力しません。

## 任意の場所の寸法メモ

- 間取りメニューの「2点の寸法メモを追加」（Mキー）を選び、図面上の2点をクリック・タップします。窓下の空間や通路、搬入経路など、壁や家具に接続していない場所にも追加できます。途中で中止するにはEscまたは別のツールを選びます。
- 追加直後は「図上」として2点間の計算値を表示します。選択して「設定」または「寸法を編集」を開き、「実測値」と自由なメモ（200文字まで）を登録できます。実測値の登録では壁や家具は動きません。入力後は「実測」として表示します。
- メモはドラッグで全体を移動できます。元に戻す・削除にも対応し、自動保存・JSON保存・SVG出力に含まれます。メモの表示文字は32文字までで、全文は設定で確認できます。
- 寸法メモは2D専用です。壁や家具の移動・寸法変更に自動追従せず、指定した2点を記録します。従来の2点メモは現行のバージョン5でもそのまま保持します。旧バージョン1・2・3・4は既存の座標を保って移行します。旧版アプリでは新形式を読み込めないため、更新版で利用してください。

## 家具の透過と外側への名前表示

- 図面の外側にあるツールバーの「透過」で家具を半透明／通常表示に切り替えます。既定は半透明です。部屋名・床面積・壁の内寸・窓寸法は家具より手前に表示し、透過をオフにしても読めるようにしています。建具・設備の色は透過しません。
- 同じツールバーの「家具名」をオンにすると、左右の図面外に家具名を表示し、引き出し線で家具の位置へつなぎます。表示時は名前まで収まる範囲に表示を調整します。家具の移動や名称変更に追従し、SVG出力にも含まれます。長い名前は表示を省略し、全文は家具の設定から確認します。
- どちらも2D用です。「設定」の表示オプションにも同じ切替があります。切替状態は端末内で覚え、間取りのJSONとは別に保存します。

## 1か所に付けるメモ

- メインの「メモ」（Nキー）を選び、書きたい位置を1回クリック・タップします。開いた設定に「窓下85 cm」「ここに棚」など200文字まで入力できます。
- 点と短い引き出し線で指定場所を示します。図面上は28文字まで表示し、全文は設定で確認できます。文字部分をドラッグすると点を固定して表示位置だけを動かせます。点をドラッグするとメモ全体が移動します。削除・元に戻すに対応します。
- 自動保存・JSON・PNG・SVG・A4印刷に含まれます。3Dには表示せず、壁や家具を動かしてもメモの位置は変わりません。

## 建具だけを外して部屋をつなぐ

- 引き戸またはドアを選び、設定の「建具だけ外して開口を残す」を押します。位置・幅・高さを維持し、2D・3Dとも扉のない開口になります。間仕切りとしての部屋名・面積は維持します。
- 「開口を閉じる」は開口を削除して壁に戻す操作です。建具を外す操作は「元に戻す」で取り消せます。
- 引き戸・ふすまの開く方向を示す矢印は表示しません。

## PNG保存とA4印刷

- 2Dのツールバーにある「PNG」で図面全体を画像として保存します。窓寸法・メモ・外側の家具名など現在オンの表示を含み、グリッドや選択用の枠・端点は含みません。負荷を抑えるため最大辺3000 px、約400万画素までに制限しています。
- 「A4印刷」で縦／横を選ぶプレビューを開き、「印刷する」でブラウザの印刷画面を開きます。印刷画面でも用紙をA4、向きをプレビューと同じ設定にしてください。PDF保存も可能です。用紙1枚への全体表示のため、実寸縮尺を保証する出力ではありません。
- PNG・A4印刷のボタンは「広く使う」でも利用できます。3Dからは2Dに戻して操作してください。端末の印刷・保存画面はブラウザにより異なります。

## 家具の縦横移動と微調整

- 2D図面の上にある移動バーの「ドラッグ」を「横だけ」「縦だけ」にすると、その方向だけへドラッグできます。「自由」で通常操作に戻ります。方向は画面の横・縦で、家具の回転角度には影響されません。
- PCではShiftを押しながらドラッグすると、動かし始めた方向へ固定できます。Shiftを離すと自由移動に戻ります（「横だけ」「縦だけ」を選んでいる場合はその設定を優先）。
- 「移動幅」は1 mm・1 cm・10 cmから選べます。家具を選び、横の矢印ボタンかキーボードの矢印キーで、その量ずつ微調整します。Shift＋矢印キーは10倍動きます。ボタンと矢印キーはドラッグ方向の設定に関係なく、示した方向へ動きます。
- 家具のドラッグも移動幅に合わせます。既存位置からの移動量を丸めるので、実測して入力した小数位置は保ちます。「設定」の「移動を目盛りに合わせる」をオフにするとドラッグ時の丸めを解除できます。壁・メモのスナップは従来通り10 cmです。
- 家具の移動は元に戻す・やり直すに対応します。入力欄の編集中は矢印キーで家具を動かしません。建具・設備は従来の壁への吸着を保ち、家具用の微調整ボタンは無効です。正確な座標は引き続き設定のX・Yからも入力できます。

## メモの文字・寸法線の表示位置を調整する

- メモの文字枠をドラッグすると、指定した点を固定したまま文字部分だけが移動し、引き出し線が追従します。点そのものをドラッグすると従来通りメモ全体が移動します。設定の「文字の位置を元に戻す」で表示位置だけを初期位置へ戻せます。
- 壁の寸法の文字をドラッグすると、寸法線を壁に対して近づける・離す・反対側へ移すことができます。壁や内寸値は変更しません。壁の設定の「寸法線の表示位置」でも調整でき、「寸法線の位置を自動に戻す」で戻せます。
- 玄関など6 m²以下の部屋に接する壁は、その部屋側に寸法を表示します。元の壁の描画順で外側へ離れてしまう場合を減らすための初期配置です。表示位置は手動調整を優先します。
- 文字位置・寸法線の位置は自動保存とJSONに記録し、PNG・SVG・印刷にも反映します。メモや寸法線だけの変更は3Dの間取り・壁・家具を動かしません。保存形式5で記録し、形式1〜4は既存の点・寸法・壁・家具を保って移行します。

## キッチン・戸棚の扉を配置する

- ツールバーまたは「建具・設備」から「戸棚の扉」を選びます。壁に吸着せず、壁に開口も作らない独立した扉です。戸棚本体は家具や造作棚を別に配置し、その前へ扉を置きます。
- 初期寸法は幅45 cm・厚さ2 cm・高さ70 cm、下端は床から85 cm。幅・高さ・下端高さ・角度・蝶番・開く側・開く角度を変更できます。両開きは2枚配置し、蝶番を左右に設定します。3Dも同じ位置・高さ・開き方を使います。
- 通常のドア・引き戸では設定の「壁へ自動で吸着」をオフにすると壁際でも自由に動かせます。オフの建具は壁の寸法変更への追従と、3Dの壁の開口も解除します。通常の部屋のドアとして扱うときはオンに戻して壁の近くへドラッグします。
- 戸棚の扉と吸着をオフにした建具は、家具と同じ移動バーの方向固定・微調整ボタン・矢印キーも利用できます。

## 特定の壁の内寸だけを隠す

- 壁本体またはその寸法の文字を選び、「設定」の「この壁の内寸を表示」をオフにします。その壁の寸法線と数値だけが消え、壁・内寸値・家具は変更しません。
- 再表示するときは、壁本体を選んで同じ設定をオンに戻します。文字を動かした位置も保持します。元に戻す・やり直すにも対応します。
- 個別設定は間取りの自動保存・JSONに記録し、PNG・SVG・A4印刷にも適用します。全体の「壁の寸法を表示」がオフの間は、個別設定がオンでも寸法を表示しません。

## コンセントを小さくする

- 配置済みのコンセントを選び、「設定」の「幅」と「プレート高さ」を変更します。例えば幅6 cm・プレート高さ4 cmにすると、初期値12×8 cmの半分の大きさになります。最小1 cm、小数も入力できます。
- 2Dの記号と3Dのプレート、PNG・SVG・印刷に反映します。「床からの設置高さ」は大きさと別に変更できます。記号を小さくしても、その周囲をクリックして選択・ドラッグできます。
- 個々のコンセントに設定し、自動保存・JSONで保持します。
