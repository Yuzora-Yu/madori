# Decisions

## 2026-10-03

- 独立したVite + React + TypeScriptアプリ。UIは `app/`、幾何処理と保存形式は `packages/` に分離。
- ブラウザ版を実装。デスクトップアプリへの変更はユーザーの判断を待つ。無料の静的ホスティングに対応し、実行時の外部API、フォント、素材、分析サービスは使わない。
- 2DはSVG。3DのThree.jsは表示時だけ遅延読込。家具と床は寸法に基づくprocedural geometry。操作・サイズ変更時のみ描画し、画素密度は最大1.7に制限。
- すべての座標・寸法はcm。任意の10 cmスナップ。壁の端点・交差点で分割し、平面グラフの面を部屋として検出。面積は壁芯基準。
- 壁の長さを指定すると始点を固定し、終点とそこへ接続した壁の端点を動かす。
- 寸法修正では壁に整列した建具の壁上の相対位置を保持する。家具ドラッグ中は壁の参照を保持して部屋検出を再計算しない。
- 家具定義と配置物を分離。定義を編集すると配置済みの該当家具へ名前・寸法・色・形状を反映。右側の編集は個別配置物のみ。元に戻すは最大50操作。
- `formatVersion: 1` を明示。未知の形式・不正データは拒否。初期保存が読めない場合は自動保存を停止し、元データを保護。JSONを端末間の移動とバックアップに使う。
- 保存はブラウザ/オリジンごとのlocalStorage。家族の端末間で自動共有はしない。家具と間取りのJSONはGitへ含めない。
- ドア・引き戸・窓・コンセントは近くの壁に整列。3Dは開口を切り、窓は腰高90 cm。コンセント高さは設置高さ。浴槽とトイレは独立設備。
- GitHub Pagesのサブパス用に相対アセットURLを使用。mainへのPushで検証・静的デプロイ。PWAシェルはビルド時のファイル一覧とハッシュから生成し、3Dも事前キャッシュ。更新は古いタブが閉じた後に適用。
- 複数階・曲線・写真認識・衝突判定・施工CADは初期リリースの範囲外。床の色は現時点では2Dのみ。

## 2026-10-04

- 寸法と面積の既定を内寸へ変更。壁の保存座標は壁芯のまま維持し、表示・入力時に隣接する壁の厚みを差し引く。面積は内側へオフセットした多角形から算出。軸に沿う四角い部屋は幅・奥行を入力でき、右・下の連続壁をまとめて移動。隣室や壁が反転・消滅する変更は適用しない。
- ドアの蝶番・開く側・開く角度を保存し、SVGとThree.jsで共通のdoorPoseを使用。ドラッグ・寸法変更は壁に対する反転方向を保持。
- 造作棚は家具のshape=shelfとして段数とbaseElevationを保存。収納段数＋1枚の棚板・側板・背板をローカルで生成。床からの高さは底面までの距離。
- formatVersion:2、dimensionBasis:interiorを明示。バージョン1は座標を保持して明示的に移行し、旧2Dのドアの見え方を既定にする。旧保存キーを引き続き読み込み、未知の形式は保護する。
