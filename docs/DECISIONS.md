# Decisions

## 2026-10-03

- 独立したVite + React + TypeScriptアプリ。UIは `app/`、幾何処理と保存形式は `packages/` に分離。
- ブラウザ版を実装。デスクトップアプリへの変更はユーザーの判断を待つ。無料の静的ホスティングに対応し、実行時の外部API、フォント、素材、分析サービスは使わない。
- 2DはSVG。3DのThree.jsは表示時だけ遅延読込。家具と床は寸法に基づくprocedural geometry。操作・サイズ変更時のみ描画し、画素密度は最大1.7に制限。
- すべての座標・寸法はcm。任意の10 cmスナップ。壁の端点・交差点で分割し、平面グラフの面を部屋として検出。面積は壁芯基準。
- 壁の長さを指定すると始点を固定し、終点とそこへ接続した壁の端点を動かす。
- 寸法修正では壁に整列した建具の壁上の相対位置を保持する。家具ドラッグ中は壁の参照を保持して部屋検出を再計算しない。
- 家具定義と配置物を分離。定義を編集すると配置済みの該当家具へ名前・寸法・色・形状を反映。右側の編集は個別配置物のみ。元に戻すは最大50操作。
- `formatVersion: 1` を明示。未知の形式・不正データは拒否。初期保存が読めない場合は自動保存を停止し、元データを保護。JSONを端末間の移動とバックアップに使う。
- 保存はブラウザ/オリジンごとのlocalStorage。家族の端末間で自動共有はしない。家具と間取りのJSONはGitへ含めない。
- ドア・引き戸・窓・コンセントは近くの壁に整列。3Dは開口を切り、窓は腰高90 cm。コンセント高さは設置高さ。浴槽とトイレは独立設備。
- GitHub Pagesのサブパス用に相対アセットURLを使用。mainへのPushで検証・静的デプロイ。PWAシェルはビルド時のファイル一覧とハッシュから生成し、3Dも事前キャッシュ。更新は古いタブが閉じた後に適用。
- 複数階・曲線・写真認識・衝突判定・施工CADは初期リリースの範囲外。床の色は現時点では2Dのみ。

## 2026-10-04

- 寸法と面積の既定を内寸へ変更。壁の保存座標は壁芯のまま維持し、表示・入力時に隣接する壁の厚みを差し引く。面積は内側へオフセットした多角形から算出。軸に沿う四角い部屋は幅・奥行を入力でき、右・下の連続壁をまとめて移動。隣室や壁が反転・消滅する変更は適用しない。
- ドアの蝶番・開く側・開く角度を保存し、SVGとThree.jsで共通のdoorPoseを使用。ドラッグ・寸法変更は壁に対する反転方向を保持。
- 造作棚は家具のshape=shelfとして段数とbaseElevationを保存。収納段数＋1枚の棚板・側板・背板をローカルで生成。床からの高さは底面までの距離。
- formatVersion:2、dimensionBasis:interiorを明示。バージョン1は座標を保持して明示的に移行し、旧2Dのドアの見え方を既定にする。旧保存キーを引き続き読み込み、未知の形式は保護する。

## 2026-10-15

- 作図領域を優先しヘッダーと編集バーを縮小。「広く使う」でヘッダー・左右パネル・補足表示を隠す。ブラウザのFullscreen APIは使わず、アプリ内で切替可能にし、保存と2D/3D切替を常に残す。
- 1100 px以下は図面を既定とし、家具・設定は一つずつ開くパネルに変更。選択だけでは図面を遮らず、明示的に寸法編集を開く。家具配置・設備選択後は図面へ戻す。通常のPC表示では左右パネルを独立に開閉し、集中表示から戻すと以前の開閉状態を復元する。
- パネルのフォーカス移動・Tab範囲・閉じた際のフォーカス復帰に対応。レイアウトは保存する間取りの形式に含めず、図面データを変更しない。
- ResizeObserverで表示領域のサイズ変更に追従し、2Dの中心位置・表示倍率を維持。操作バーと補足説明は右下へ寄せて作図の中央を空ける。

- 2Dの画面移動は右ボタンドラッグを主操作に変更し、3Dの操作と統一。家具・部屋・壁の上でも右ボタンを作図・選択として扱わず画面移動を優先。Alt＋ドラッグ・中ボタン・移動ツールも保持する。右クリックの標準メニューは図面上のみ抑止。

- 窓の位置は隣接壁の内側から窓の端までの距離で入力。壁の始点・終点の描画順によらず横は左→右、縦は上→下、斜めはA→Bで測る。途中で分割された壁はその区間を基準にし、図面に測定端を明示する。幅変更はA側の距離を保持し、壁内寸を越える変更は拒否する。
- 窓の下端の高さは既存baseElevationを使用し、省略時90 cm。3Dの窓と壁の開口が共通の値を使う。見込みも2D・3Dの厚みに反映。位置・寸法の既存フィールドに記録するため形式変更・移行は不要。選択用の測定ガイドはSVG出力から除外。

- 任意の2点の寸法メモをdimensions配列として保存。幾何からの計算値と任意の実測valueを分け、実測値で壁や家具を自動補正しない。メモの移動・削除・元に戻す・JSON/SVG保存に対応し、3D表示には含めない。
- 保存形式をformatVersion:3へ更新。1→2の既存移行後、2→3で空のdimensionsを補う。旧座標は維持し、新形式では配列・測定値・IDを検証。未知の形式や不正データは引き続き拒否して元データを保護する。
- 2D家具は塗りを既定40%の不透明度とし、輪郭は維持。部屋名・面積は家具の後に描画し、家具透過オフでも可読にする。引き出し線付き家具名は外壁外に決定的に配置し、片側のラベル間隔を34 cm以上に保つ。
- 家具透過・家具名の表示スイッチは作図領域外のツールバーに配置。表示設定のみ別のlocalStorageキーmadori.view.v1に保持。図面の全体表示とSVG出力では外側のラベルも範囲へ含める。

## 2026-10-15 点メモ・開口・図面出力

- 主メモ操作を1点クリック＋自由文のnotes配列に変更。既存のdimensions配列の2点メモは保持し、Mキーと間取りメニューから作成可能。保存形式を4に上げ、3→4は空のnotesを追加する明示的移行。未知形式・不正値は保護を継続する。
- 建具を取り外した状態をopening種別で保存。元の位置・幅・高さを維持し、壁の開口処理をドアと共用。扉モデルは生成せず、部屋検出の壁自体は保持する。引き戸の方向矢印は削除。
- 壁寸法・窓寸法は家具より手前に描画。窓幅・高さ・両端からの距離を既定で常時表示。同じ壁の窓は決定的な段に分け、全体表示と出力の範囲にも含める。
- PNGと印刷は2D SVGの複製から編集専用マーカー・グリッドを除去して生成。PNGは最大辺3000 pxかつ約400万画素に制限し端末内canvasで変換。印刷はSVG画像とA4縦横の専用印刷CSSを使い、別ウィンドウ・外部変換・追加ライブラリは使わない。ブラウザ印刷ダイアログの確定は利用者が行う。

## 2026-10-15 家具の移動操作

- 家具用に画面のX／Y方向固定、Shiftドラッグの優勢方向固定、1 mm・1 cm・10 cmの相対移動を追加。家具は既定1 cm単位とし、実測位置の端数を保持するため絶対座標ではなくドラッグ開始位置からの変位を丸める。建具・壁・メモの従来の吸着・スナップは変更しない。
- 矢印ボタンと矢印キーは選択家具だけに適用し、Shift＋矢印は選択移動幅の10倍。入力欄・モーダル・ドラッグ中のキーボード移動は抑止する。方向固定はドラッグに適用し、明示した矢印操作はその方向を優先する。
- 移動バーは図面外に置き、家具の選択時に図面サイズが変わらないよう2Dでは一定領域を確保。方向・移動幅は編集状態とし保存形式は変更しない。座標範囲は既存JSONと同じ±50000 cm。

## 2026-10-16 独自ドメイン接続

- 正式な起動URLをhttps://yu-zora.com/tools/madori/とする。紹介ページのTool06_madoriとは分離する。既存EntaMemoryと同じCloudflare WorkerによるGitHub Pages資材の中継を採用し、アプリ更新のGit Push→Pages自動公開を維持する。
- Workerはmadoriの完全一致と配下の2ルートのみを所有。GET／HEADの静的資材だけを中継し、Cookie・Authorization・クエリを上流へ転送しない。リダイレクト先も独自ドメイン内へ戻す。サービスワーカーのscopeはアプリ配下に限定。
- オリジン変更で既存localStorageを共有できないためJSON保存・読込で移行する。旧画面のデータ取り出しを守るためGitHub Pagesからの自動リダイレクトは行わない。

## 2026-10-18 注釈の表示位置と戸棚の扉

- 点メモの測定位置x/yと文字枠の相対labelOffsetを分離。文字枠をドラッグするとオフセットのみ、点をドラッグすると全体を移動。引き出し線は文字枠の近い端へ接続し、全体表示・画像出力の範囲にも文字位置を含める。
- 壁の寸法線の位置は壁の法線方向のdimensionOffsetとして保存。ドラッグまたは数値で表示位置だけ変更し、内寸計算と壁の端点は保持。自動配置は6 m²以下の最小隣室側を優先し、手動指定がある場合はそれを優先する。
- cabinetDoor種別は幅45 cm・厚さ2 cm・高さ70 cm・下端85 cmを初期値とする独立した戸棚の扉。ドアの開き方の計算は共用し、壁の開口とは分離。通常建具もwallSnap=falseで吸着・寸法変更への追従・3D開口を解除できる。自由配置の建具は家具用の移動幅・方向固定・微調整を共用する。
- 形式5へ更新。4→5は新しい任意フィールドを追加する明示的移行とし、旧座標やメモ位置の再計算はしない。オフセット・吸着設定の型と範囲を検証。未知の保存形式の保護を継続する。

## 2026-10-18 壁ごとの内寸表示

- 壁の任意フィールドdimensionHiddenで寸法線と数値の個別非表示を保持。省略・falseは表示、trueは非表示とする形式5への後方互換の追加で、既存データの書き換え・移行は行わない。読み込み時はbooleanのみ受け入れる。
- 寸法の表示位置と壁の形状・内寸値は保持し、壁本体の選択から再表示できる。全体の寸法表示がオフの場合は全体設定を優先。SVG・PNG・印刷も同じ2D描画を用いる。非表示にした寸法のオフセットは図面の出力範囲を広げない。

## 2026-10-19 コンセントのサイズ

- 2Dコンセントの固定26 cm記号を、保存済みのwidth/depthに合わせて拡縮する。depthはプレート高さとして表示し、3Dの固定12 cmの高さも同じ値に統一。heightは従来どおり床からの設置高さとし、入力欄を分離する。既存フィールドだけを使うため形式5の変更・移行は不要。
- 小さい記号も選べるよう、編集用の透明な当たり判定は各辺26 cm以上を確保。PNG・SVG・印刷からは除外し、表示する記号にはサイズの下限を設けない（入力の既存下限1 cmは維持）。

## 2026-10-19 寸法の表示設定の統一

- 2D寸法はマスターのenabled、壁・窓・開口・家具・設備・メモ・面積の7種類、壁／アイテムのdimensionHiddenの順に判定する。マスターを切り替えても種類別・個別設定は保持。家具・設備のみ既定オフ、その他はオンとし、従来の窓の表示設定は引き継ぐ。選択しただけで非表示の窓寸法が再表示される例外は廃止する。
- 一括・種類別設定は従来のmadori.view.v1へ保存し、アイテムの任意boolean dimensionHiddenは既存の形式5へ後方互換で追加。個別設定のJSON検証はbooleanのみ受け入れ、形状や寸法を変更しない。読み込み時の移行・形式の追加は不要。
- 窓と壁に沿うドア・引き戸・開口の寸法線を共用し、同一壁では表示対象のID順で段を割り当てる。幅は開口全体であり有効開口幅の推定はしない。独立した家具・設備の幅・奥行・高さもSVGで描画し、回転後の寸法文字の範囲を画像出力に含める。
- 非表示の壁の寸法位置やメモは表示範囲の計算から除外し、元データは保持。PNG・SVG・A4は同じ表示状態を複製する。UIの寸法設定は図面外のボタンから既存の設定パネルへスクロールし、モバイルでもパネル内に収める。
